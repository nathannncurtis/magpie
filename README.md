# Magpie

The browser you shape. A free, open-source browser for iPhone.

Ads, trackers and cookie banners blocked, mods by anyone, and an optional Skim that reads the top results on the phone itself. No account, nothing collected.

Early work. The design lives in `docs/`: the spec in `docs/spec/` and the board in `docs/design/`.
